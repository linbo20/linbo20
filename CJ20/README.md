# CJ20：UWB 呼吸、心脏候选波形和体动分析

## 使用

Python 3.10+，安装依赖后，只修改 `main.py` 的 `INPUT_FOLDER`（直接存放 BIN 的目录）：

```bash
pip install -r requirements.txt
python main.py
```

目录自身或父目录需包含 `radar_2026-11-05-19-36-34` 格式。输出自动存到输入目录内的 `vitals_output/`。

协议固定为 100 Hz、8 RX、32 taps（65–96）、小端 int16、Q 在前 I 在后、无帧头、每 BIN 100 帧。仅最后文件允许不足 100 帧。文件缺号、重复编号、多 COM 数据流、非法大小会报错。文件名格式 `COM21_radar_0.bin`，首编号允许 0 或 1。字节长度正确不代表协议已核验，请以设备协议为准。

## 相位与波形

全部信号处理固定第二通道，即零基索引 `RX1`，包括体动评估、目标单元选择及生理波形。体动分数为 RX1 各 tap 相邻复数变化的归一化能量，经 0.2 秒平滑；阈值采用固定下限与 MAD，并保留大变化兜底阈值。体动前后扩展 3 秒。

剔除扩展体动段后，按每个 tap 的复数 CIR 时间标准差选择最大者：`std(z)=sqrt(mean(abs(z-mean(z))**2))`。低幅度或零变化单元排除。固定全程使用该 tap，元数据输出全部 tap 标准差和选中索引。复数 std 能保留相位微动；只计算 `std(abs(z))` 可能遗漏幅度稳定的相位变化。std 不证明选中胸部，也可能选中杂波或干扰。全程选 tap 属于离线策略，使用了整段数据，尚未实现实时目标跟踪。

对所选复数 CIR 逐帧计算 MDACM 相位：

```text
Δφ[n] = (I[n]·(Q[n]−Q[n−1]) − Q[n]·(I[n]−I[n−1])) / (I[n]²+Q[n]²)
φ[n] = φ[n−1] + Δφ[n]
```

每个有效片段以零相位起始，不使用 atan/unwrap。低幅值点和体动处断开并重启，不跨缺口累加。MDACM 为离散微分近似，需要帧间相位变化足够小且 IQ 远离零点；未做 IQ 圆拟合，静态偏置、幅度波动仍可能导致误差。

**每 5 秒处理一块并连续传递 SOS 滤波器状态**，呼吸频带 0.1–0.6 Hz、心脏候选频带 0.8–2.5 Hz，四阶 Butterworth 因果滤波。最后不足 5 秒的块照常输出。不对每块独立滤波后硬拼接，因为 0.1 Hz 一个周期就需要 10 秒。状态只在污染/低幅值缺口重置。每段最初 5 秒波形保留但 `waveform_valid=False`，提示滤波启动瞬态；5 秒后仍不能保证所有瞬态完全消失。

每帧均保留。污染波形为 NaN，不能填零用于分析。波形为相位代理（rad），不是位移或 ECG。因果滤波有频率相关延迟，时间戳指输入帧时间，不能视为无延迟心搏时刻；逐搏间期需要 ECG/PPG 验证。

## 速率更新与时间点

速率计算独立于 5 秒滤波分块，使用当前速率窗口内的 MDACM 相位去趋势及零相位带通，再进行 Hann 周期图峰值估计和局部插值，避免整段因果波形启动瞬态及窗口外样本影响。

- 不满或等于 5 秒不输出速率记录。
- 第一条在 501 帧（按采集时长计 5.01 秒）输出；随后在 10、15、20、25 秒时使用开始至当前的全部数据。
- 从 30 秒起，每 5 秒更新最近 30 秒：`[0,30)`、`[5,35)`、`[10,40)` 等。
- 记录结束不是常规更新点时，额外输出最后一条；不足 30 秒仍使用开始至末尾数据。
- 每个窗口含污染/低幅值无效相位时保留记录，但速率 NaN；不把多个干净片段拼起来计算频谱。

`estimate_time` / `estimate_s` 为该次结果对应的**窗口最后一帧时间**。`start_time` 和 `end_time_exclusive` 给出实际窗口；`center_time` 也一并保留便于对齐。30 秒窗口在 100 Hz 下最后一帧是 29.99 秒，不是 30.00 秒。第一条对应最后一帧 5.00 秒，窗口采集时长 5.01 秒。

`warmup_window=True` 表示使用不足 30 秒数据的初步估计。短窗呼吸可能不足一个周期，真实频率分辨率约为 `60 / window_duration_s` 次/分：5 秒约 12、30 秒约 2。短窗谱集中度高也不能证明估计可信；插值不增加真实分辨率。频谱质量低于阈值或呼吸整数倍谐波歧义时输出 NaN。有效标记只表示通过当前工程检查，不是临床可信度。

绝对时间：`目录开始时间 + frame / 100 秒`，默认中国时区 `Asia/Shanghai`。目录必须保留实际首文件；没有硬件时间戳时不能识别文件内部丢帧、暂停、时钟漂移或命名与首帧的偏差。

## 输出

| 文件 | 内容 |
| --- | --- |
| `frames.csv` / `waveforms.npz` | 每帧相对时间、体动分数、原始体动/扩展污染标记、波形有效标记、MDACM 相位、呼吸/心脏候选波形；CSV 另有绝对时间 |
| `rates_30s.csv` | 初步及正式窗口速率，含窗口帧范围、时长、结果时间点、中心时间、有效比例、质量、谐波标记及 warmup_window |
| `candidate_ibi.csv` | 有效窗口覆盖下的连续有效波形候选峰间期，不跨缺口连接；validated_for_hrv 始终 False |
| `metadata.json` | 配置、选中 RX/tap、全部 tap std、时间假设、帧与文件映射 |
| `overview.png` | 整段体动、呼吸/心脏候选波形及速率随 estimate_s 变化的图 |

`phase_rad` 是片段内相对累计相位，`waveform_valid` 标记滤波波形是否度过初始 5 秒；速率窗口独立从相位估计，因此不因连续波形最初 5 秒的启动标记永久阻断初步估计。体动分数是无量纲代理，不是加速度或速度。

## HRV 与限制

呼吸谐波、杂波、多径均可能进入心脏频带。候选波形峰不是已验证心搏，候选 IBI 不是已验证 NN 间期，`interval_plausible` 只代表落在配置心率范围。不要直接用窗口心率计算 HRV。需同步 ECG/PPG 对照，修正误检漏检、异常搏动，并在连续有效片段计算 HRV。本项目不默认输出未经验证的 RMSSD/SDNN/LF/HF。当前仅为单人固定目标的离线基线；真实数据精度尚未验证，整段 CIR 需要内存。

## 模块与测试

`config.py` 管理参数；`io.py` 解析和时间；`signals.py` 实现 RX1/std/MDACM/体动/5 秒连续滤波；`physiology.py` 负责速率和候选间期；`pipeline.py` 导出和绘图。日常仅需改 main.py 输入目录。

```bash
python -m unittest discover -s tests -v
```

测试包括 MDACM 与已知相位对比、第二通道/std 选 tap、分块滤波状态连续性、初步及滑窗调度、合成速率、体动、谐波、零信号、Q/I/时间/缺号校验及全流程导出。
